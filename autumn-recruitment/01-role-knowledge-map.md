# AI Agent / 全栈 / 前端岗位知识地图

## 一、共同基础

三个岗位共享的软件工程底座：

- 数据结构与算法；
- 计算机网络；
- 操作系统基础；
- 数据库；
- Git、测试、调试、工程协作。

目标不是背知识点，而是能解释：

> 为什么需要它，它解决什么问题，在真实系统中如何使用。

---

## 二、前端开发

### 必须掌握

- JavaScript / TypeScript；
- 浏览器运行机制；
- 事件循环、异步模型；
- Vue / React 原理；
- 状态管理；
- 工程化构建；
- 性能优化；
- Web 安全。

### 当前策略

已有基础，不作为主要补强方向。

重点补：

- JS 底层；
- 浏览器原理；
- Agent 场景下的流式 UI、任务状态展示和复杂交互。

---

## 三、全栈开发

### 必须掌握

- 后端语言与框架；
- API 设计；
- MySQL、Redis；
- 事务与一致性；
- 异步任务；
- 消息队列；
- 状态机；
- 日志、测试、部署。

核心目标：

> 能解释一个请求进入系统后，如何流转、如何失败恢复、如何保证可靠。

---

## 四、AI Agent 开发

### 必须掌握

- LLM 基础；
- Prompt 与 Context Engineering；
- Structured Output；
- Tool Calling；
- RAG；
- Agent Loop；
- Memory；
- Workflow；
- MCP；
- Trace 与 Evaluation。

核心理解：

Agent 不是简单调用模型，而是：

```text
用户输入
→ 构造上下文
→ 调用模型
→ 判断工具需求
→ 执行工具
→ 写回结果
→ 决定继续或结束
→ 记录轨迹
```

---
