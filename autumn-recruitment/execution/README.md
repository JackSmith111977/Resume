# 工作日碎片化执行系统 v2

> 场景：实习工作日中的不固定空档。  
> 原则：能力、项目、简历投递和反馈并行；不依赖周末维持路线。

## 1. 执行单位

| 类型 | 时间 | 适合任务 |
| --- | ---: | --- |
| S | 10～15 分钟 | 无标签识别、复述、岗位记录、简历审计、单个追问 |
| M | 20～30 分钟 | 推导、接口/状态设计、小段实现、经历素材、反馈复盘 |
| L | 30～45 分钟 | 完整算法、项目纵切、模拟面试、定向简历和投递 |

任务进入 Ready 前必须能在 45 分钟内产生一个可验证检查点。

## 2. 每日最低标准

### 最低线

- 一个 S 任务；
- 留下下一步第一动作。

### 正常线

- 一个 M 任务；
- 一个 S 复盘或求职任务。

### 充足空档

- 一个 L 任务；
- 一个 S 总结。

不补时长，只补关键产物。繁忙日不能用来暂停整个投递流水线。

## 3. 开始前一分钟

```text
所属流水线：能力 / 项目 / 求职 / 反馈
当前主题：
这次只解决什么：
上次停在哪里：
完成判定：
```

禁止以“学习 Spring”“完善项目”“准备秋招”这类宽泛任务开工。

## 4. 结束前两分钟

```text
本次产物：
暴露的问题：
是否改变 P0：
下一步第一动作：
相关文件/代码/岗位：
```

下一步必须可以直接执行，例如“为未知工具增加错误测试”，而不是“继续研究 Agent”。

## 5. AI 使用边界

### 独立区

首轮不让 AI 生成答案：

- 算法方向、状态和实现；
- 核心技术取舍；
- 简历事实和个人贡献判断；
- 面试口述；
- 项目是否应该增加范围。

### 协作区

独立尝试后 AI 可以：

- 提供分级提示；
- 审查代码和 Diff；
- 生成反例和失败注入；
- 扮演面试官；
- 比较方案；
- 压缩复盘和维护任务队列。

### 工程区

AI Coding 必须保留：

- 需求和验收标准；
- 人工方案判断；
- 测试；
- Diff 审查；
- 失败场景验证；
- 可解释的最终代码。

## 6. 固定五日循环

| 日 | 能力主线 | 项目/求职副线 | 典型产物 |
| --- | --- | --- | --- |
| 周一 | 算法识别 | 岗位池和反馈 | 推导卡 + 岗位记录 |
| 周二 | CS/后端链路 | 美团/简历 | 链路图 + bullet |
| 周三 | 算法实现 | Agent 原理/框架 | Python 代码 + 最小实现 |
| 周四 | Agent 项目纵切 | 前端手写 | 可运行切片 + JS/TS 代码 |
| 周五 | 模拟与复现 | 投递和周复盘 | 指标、投递、P0 调整 |

遇到真实笔试或面试时可替换副线，但算法每周至少三次，前端独立手写每周至少一次。

## 7. 任务状态

```text
BACKLOG
→ READY
→ DOING
→ REVIEW
→ VERIFIED
```

知识能力另使用：

```text
TODO
→ LEARNING
→ CAN_EXPLAIN
→ CAN_IMPLEMENT
→ USED_IN_PROJECT
→ INTERVIEW_READY
```

`DONE` 不等于看完，`VERIFIED` 必须有复测、测试、演示或真实反馈。

## 8. WIP 限制

- DOING 最多一个编码任务和一个轻任务；
- 同时只有一个 Agent 项目主切片；
- 每周最多五个 P0；
- 由面试反馈新增的 P0 每周最多三个；
- 新技术进入项目前必须替换或删除一个同级范围。

## 9. 每周指标

### 算法

- 无标签分析 12～15；
- 独立完整实现 6～8；
- 7 天复现 4～6；
- 模拟笔试一次；
- ACM 输入输出两次；
- 识别率、通过率和主要错因。

### 项目

- 至少一个可运行纵向检查点；
- Trace / Tool / RAG / Eval 状态；
- 新增失败样本和修复证据；
- 是否发生范围膨胀。

### 求职

- 新增岗位 20～30；
- 高匹配精投至少 10；
- 简历版本和经历更新；
- 笔试/面试状态。

### 前端与后端

- 前端独立手写或调试一次；
- 一个后端/CS 链路、接口、SQL 或排障证据；
- 一次项目或基础知识脱稿口述。

## 10. 周复盘

```text
新增独立能力：
新增求职证据：
真实失败和标签：
项目是否仍满足六项 MVP：
本周删除或降级的范围：
下周最多五个 P0：
```

## 11. 周末规则

周末默认休息。可选用途：

- 完成本地环境整合；
- 录制项目演示；
- 做一次完整模拟笔试或面试；
- 补一个因实习完全中断的关键检查点。

未完成任务应重新拆分进入下周，不通过透支周末掩盖范围错误。
