# 工作日碎片化执行系统 v2.2

> 场景：实习工作日中的不固定空档。  
> 原则：能力、项目、简历投递和反馈并行；不依赖周末维持路线。

> AI 协作规则以 [`../AGENTS.md`](../AGENTS.md) 为准。当前日期任务以 [`../schedule/calendar-2026-08-04-to-09-06.md`](../schedule/calendar-2026-08-04-to-09-06.md) 为准，状态和复测以 [`../schedule/progress-ledger.md`](../schedule/progress-ledger.md) 为准。

## 1. 执行入口

每天按以下顺序：

1. 读取当前日期日程；
2. 检查总账中的 `DUE`、`DOING` 和当前最多五个 P0；
3. 判断当天容量：最低 / 标准 / 充足；
4. 只选择一个主任务和最多一个轻任务；
5. 复制 [`../schedule/daily-log-template.md`](../schedule/daily-log-template.md)；
6. 完成 Human First、AI 协作、验收和归档；
7. 更新总账和 D+1 / D+3 / D+7 复测；
8. 周五使用 [`../schedule/weekly-review-template.md`](../schedule/weekly-review-template.md)。

知识依赖和从具体到抽象的顺序见 [`../schedule/learning-sequence.md`](../schedule/learning-sequence.md)。

## 2. 执行单位

| 类型 | 时间 | 适合任务 |
| --- | ---: | --- |
| S | 10～15 分钟 | 无标签识别、复述、到期复测、岗位记录、简历审计、单个追问 |
| M | 20～30 分钟 | 推导、接口/状态设计、小段实现、经历素材、反馈复盘 |
| L | 30～45 分钟 | 完整算法、项目纵切、模拟面试、定向简历和投递 |

任务进入 `READY` 前必须能在 45 分钟内产生一个可验证检查点。60～90 分钟模拟允许作为扩展 L，但必须提前安排。

## 3. 每日容量

### 最低档

- 一个 S 到期复测或当天主任务的缩小版本；
- 留下下一步第一动作。

### 标准档

- 一个 M 主任务；
- 一个 S 复测、算法识别或求职任务；
- 5 分钟归档。

### 充足档

- 一个 L 主任务；
- 一个 M 支撑任务；
- 一个 S 求职或复测任务；
- 5～10 分钟归档。

不补时长，只补关键产物。时间不足时保留知识依赖、到期复测和项目主链路，删除可选任务。

## 4. 任务契约

```text
日期：
日程任务 ID：
所属流水线：能力 / 项目 / 求职 / 反馈
领域：ALG / CS / BE / FE / AG / PROJ / JOB / REV
深度：D0 / D1 / D2 / D3 / D4
任务尺寸：S / M / L
协作模式：/tutor /exam /interview /review /build /archive
最高援助：A0 / A1 / A2 / A3 / A4
独立尝试时间：
可见产物：
完成判定：
明确不做：
```

禁止以“学习 Spring”“完善项目”“准备秋招”这类无法完成的宽泛任务开工。

## 5. 知识深度顺序

所有主题默认遵循：

```text
真实问题 / 具体样例
→ 最小实现或可观察现象
→ 关键机制和不变量
→ 失败模式与相邻概念
→ 抽象模型与方案取舍
→ 新场景迁移与面试表达
```

| 深度 | 通过条件 |
| --- | --- |
| D0 定位 | 无辅助诊断并标记真实卡点 |
| D1 具体 | 能处理一个明确样例并展示状态变化 |
| D2 机制 | 能解释机制、不变量或数据流 |
| D3 抽象 | 能处理失败、反例并比较方案 |
| D4 迁移 | 能解决陌生场景、系统设计或真实面试问题 |

AI 生成的高级解释不能代替前置层证据。

## 6. AI 协作模式与援助等级

详细规则见 [`human-ai-collaboration.md`](./human-ai-collaboration.md)。

### 六种模式

| 模式 | 用途 | 默认行为 |
| --- | --- | --- |
| `/tutor` | 学习新概念、算法推导 | 先预测，一次一问，分级提示，最后复述 |
| `/exam` | 笔试、复现、无辅助测试 | A0，中途不提示，结束后统一评分 |
| `/interview` | 项目深挖和模拟面试 | 动态追问，不因术语正确就判定掌握 |
| `/review` | 方案、代码、简历对抗审查 | 先找问题和反例，不立即重写 |
| `/build` | 明确范围后的实现 | 读上下文、最小计划、实现、测试、Diff 摘要 |
| `/archive` | 归档和状态更新 | 区分人/AI 贡献，安排下一步和复测 |

### 五级援助

| 等级 | AI 权限 |
| --- | --- |
| A0 | 只出题、计时、记录，不提示 |
| A1 | 只问引导问题 |
| A2 | 给类别、方向、反例或局部线索 |
| A3 | 给状态、步骤、伪代码或局部示例 |
| A4 | 可执行完整代码、文档、整理和修改 |

默认：算法首轮 A1，概念 A2，模拟 A0，核心方案 A2，确认后的工程实现 A4，事实判断 A1，确认事实后的措辞 A4。

## 7. 人与 AI 的边界

### 人必须完成

- 首次预测、推导和回答；
- 项目目标、验收、架构取舍和范围；
- 简历事实、个人贡献和指标真实性；
- Diff、测试、失败场景和最终状态升级；
- 无辅助复测和面试表达。

### AI 可以完成

- 诊断、提示、反例和迁移题；
- 检索、代码库扫描和方案比较；
- 明确范围后的实现、测试和文档；
- 对抗性审查、模拟面试和反馈聚合；
- 维护日程、总账和复测队列。

AI 生成的成品不计入学习掌握度。每次 AI 协作必须留下至少一个未来的无 AI 任务。

## 8. 固定周骨架

具体日期和任务 ID 见当前日历。周骨架仅用于降低选择成本：

| 日 | 能力主线 | 项目/求职副线 |
| --- | --- | --- |
| 周一 | 算法具体模式与混合识别 | 岗位池和上周反馈 |
| 周二 | 真实请求、CS 和后端机制 | 美团经历和简历 |
| 周三 | 算法完整实现 | Agent 原理或框架 |
| 周四 | Agent 项目纵向切片 | 前端手写和 AI UI |
| 周五 | A0 模拟、复现和抽象迁移 | 投递、反馈和周复盘 |

真实笔试或面试可替换当天可选任务，但到期复测和项目主链路不得连续取消两次。

## 9. 状态

任务状态：

```text
BACKLOG → READY → DOING → REVIEW → VERIFIED
```

能力状态：

```text
TODO → LEARNING → CAN_EXPLAIN → CAN_IMPLEMENT → USED_IN_PROJECT → INTERVIEW_READY
```

升级要求：

- 阅读最多进入 `LEARNING`；
- `CAN_EXPLAIN`：无辅助口述；
- `CAN_IMPLEMENT`：独立完成核心部分；
- `USED_IN_PROJECT`：真实代码、测试和失败处理；
- `INTERVIEW_READY`：D4 迁移、模拟追问或真实面试证据；
- `VERIFIED`：有复测、测试、演示或真实反馈。

## 10. WIP 和日程调整

- `DOING` 最多一个主任务和一个轻任务；
- 同时只有一个 Agent 项目主切片；
- 每周最多五个 P0；
- 新技术进入 P0 前必须替换或删除一个同级范围；
- 未完成任务不得使整份日历整体顺延；
- 应重新拆分，并在周复盘中继续、降级或删除；
- AI 执行更快不能成为增加每日任务和扩张范围的理由。

## 11. 周指标

### 算法

- 无标签分析 12～15；
- 独立完整实现 6～8；
- D+7 复现 4～6；
- 模拟笔试一次；
- ACM 输入输出两次；
- 识别率、通过率和主要错因。

### 项目

- 至少一个可运行纵向检查点；
- Trace / Tool / RAG / Citation / Eval 状态；
- 新增失败样本和修复证据；
- 用户能解释和修改 AI 生成的关键代码；
- 是否发生范围膨胀。

### 求职

- 新增岗位 20～30；
- 高匹配精投至少 10；
- 简历版本和经历更新；
- 笔试/面试反馈 100% 记录。

### 前端和后端

- 前端独立手写或调试一次；
- 一个后端/CS 链路、接口、SQL 或排障证据；
- 一次脱稿口述或系统设计迁移。

### 人机协作

- A0/A1 核心训练数；
- AI 帮助后通过无辅助复测的任务数；
- 出现“AI 会、人不会”的任务数；
- 未解释 AI 关键代码数；
- 被测试、事实核验或反馈推翻的 AI 输出。

## 12. 周末规则

周末默认休息。可选：本地整合、演示录制、A0 模拟、D+7 复测或真实面试准备。

未完成任务应重新拆分，不通过透支周末、整体顺延日历或提高 AI 代做比例掩盖范围错误。
