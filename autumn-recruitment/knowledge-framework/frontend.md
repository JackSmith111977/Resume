# 前端开发知识路线

> 定位：已有相对优势，不做从零重学。  
> 目标：P0 核心达到 L3，能够支撑前端岗位并作为 Agent 产品的交互层。

## 1. JavaScript 与 TypeScript

### P0：JavaScript 运行机制（目标 L2～L3）

必须掌握：

- 作用域、闭包、执行上下文；
- 原型链、继承、`this`；
- Promise、async/await、异常传播；
- 宏任务、微任务和事件循环；
- 模块系统、浅拷贝与深拷贝；
- 常见数组、对象和函数式操作。

独立实现：

- 防抖、节流；
- Promise 并发控制；
- 发布订阅；
- 简化版深拷贝；
- 异步轮询与取消。

### P0：TypeScript（目标 L3）

必须掌握：

- 联合、交叉、泛型；
- 类型收窄和类型守卫；
- `keyof`、索引访问、映射类型、条件类型；
- 接口与类型别名的边界；
- API DTO、状态机和工具 Schema 的类型设计；
- 编译期类型与运行时校验的区别。

验收：为一个 Agent 任务状态机设计完整类型，并使用运行时校验保护外部输入。

## 2. 浏览器与 Web 平台

### P0：浏览器核心（目标 L2）

- URL 到页面显示的完整过程；
- DNS、TCP/TLS、HTTP 请求；
- HTML/CSS 解析、渲染树、布局、绘制与合成；
- 重排、重绘和合成层；
- 浏览器缓存、Cookie、Storage；
- 同源策略、CORS、XSS、CSRF；
- 性能指标与基本分析方法。

验收：能分析“页面首屏慢”或“交互卡顿”，给出测量、定位和优化顺序。

### P1：Web 能力边界（目标 L1～L2）

- Web Worker、Service Worker；
- SSE、WebSocket、流式响应；
- 文件上传、下载与大文件处理；
- AbortController；
- IntersectionObserver、ResizeObserver。

## 3. 框架与状态管理

### P0：React / Next.js（目标 L3）

结合现有简历主栈重点掌握：

- 函数组件、Hooks、闭包与依赖；
- 状态更新、批处理和渲染触发；
- 组件边界、受控与非受控；
- Context 与外部 Store 的取舍；
- Server Component、Client Component、SSR/SSG/ISR；
- 数据获取、缓存、错误边界和 Suspense；
- Next.js 中服务端与客户端安全边界。

### P1：Vue（目标 L2）

- 响应式、依赖追踪；
- `ref`、`reactive`、`computed`、`watch`；
- 生命周期和组件通信；
- 路由与状态管理；
- Vue 与 React 在更新模型上的差异。

策略：不同时深挖两套源码；React/Next.js 作为简历主叙事，Vue 保持可开发与可面试能力。

## 4. 工程化、测试与质量

### P0（目标 L2～L3）

- Vite / Webpack 的入口、依赖图、转换、打包和代码分割；
- ESM、CommonJS、Tree Shaking；
- 包管理、锁文件、依赖冲突；
- ESLint、格式化与提交检查；
- 单元测试、组件测试、端到端测试的边界；
- 错误监控、Source Map、前端日志；
- CI/CD 与多环境配置。

验收：为一个前端功能补齐单测、端到端关键路径和构建检查。

## 5. 性能与安全

### P0（目标 L2～L3）

性能：

- 加载性能、渲染性能和运行时性能分开分析；
- 图片、字体、资源加载；
- 分包、懒加载、预加载；
- 长列表、虚拟化；
- 避免无效渲染和主线程长任务。

安全：

- XSS、CSRF、CORS 的区别；
- Token、Cookie 与前端存储风险；
- 富文本和模型输出的安全渲染；
- 敏感配置不得进入客户端。

## 6. AI 原生交互（岗位差异化，P0，目标 L3）

必须掌握：

- Token 流式输出与增量渲染；
- 消息状态：发送、运行、等待工具、成功、失败、取消；
- 长任务进度和断线恢复；
- Tool Calling 的用户确认与权限提示；
- 引用、来源和执行轨迹展示；
- 乐观更新与服务端真实状态的协调；
- 对话、任务和工作区三种产品模型；
- 错误恢复、重试和人工接管。

独立产物：设计一个 Agent 工作台前端，至少包含对话流、任务状态、工具确认、引用和 Trace 展示。

## 7. 碎片化学习任务

### S 型（10～15 分钟）

- 口述一次事件循环；
- 判断一个 Hooks 依赖问题；
- 解释一种缓存或安全机制；
- 设计一个 Agent UI 状态。

### M 型（20～30 分钟）

- 手写一个 JS 高频函数；
- 为一个组件画数据流；
- 分析一段渲染或异步 Bug；
- 为流式响应设计 reducer 或状态机。

### L 型（30～45 分钟）

- 完成一个 Agent UI 纵向切片；
- 补测试和错误恢复；
- 做一次前端项目深挖模拟。

## 8. 前端验收门槛

投递前至少能够：

- 不看资料解释事件循环、渲染流程和常见安全问题；
- 独立完成 Promise 并发控制等高频手写；
- 深入解释一个 React/Next.js 项目的渲染与数据流；
- 设计并实现流式 Agent UI；
- 从性能、可靠性、安全和用户体验四方面复盘前端方案。
