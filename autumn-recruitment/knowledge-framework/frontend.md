# 前端开发知识路线 v2

> 定位：已有相对优势，不从零重学；恢复独立手写、调试和基础表达，并形成 AI 原生交互差异化。  
> 目标：P0 核心达到 L2～L3，每周至少一次脱离 AI 的前端编码或排障。

## 1. HTML 与 CSS 基础（P0，目标 L2）

### HTML

- 语义化结构；
- 表单、校验和可访问性；
- 资源加载；
- SEO 与元信息基础；
- ARIA 的适用边界；
- 不可信 HTML 和富文本安全。

### CSS

- 盒模型、层叠、继承和优先级；
- 正常流、定位、BFC 和层叠上下文；
- Flex、Grid；
- 响应式布局和媒体查询；
- 尺寸、溢出、滚动和粘性定位；
- 动画、合成与性能；
- Design Token 和样式隔离。

验收：不用组件库完成一个响应式工作台布局，并解释布局、层叠和滚动问题。

## 2. JavaScript 运行机制（P0，目标 L2～L3）

必须掌握：

- 作用域、闭包、执行上下文；
- 原型链、继承和 `this`；
- Promise、async/await 和异常传播；
- 宏任务、微任务和事件循环；
- 模块系统；
- 值、引用、浅拷贝和深拷贝；
- 常见数组、对象和函数式操作。

独立实现：

- 防抖、节流；
- Promise 并发控制；
- 发布订阅；
- 简化版深拷贝；
- 带取消和退避的异步轮询。

## 3. TypeScript（P0，目标 L3）

- 联合、交叉、泛型；
- 类型收窄和类型守卫；
- `keyof`、索引访问、映射和条件类型；
- 接口与类型别名；
- DTO、状态机和 Tool Schema 类型设计；
- 编译期类型与运行时校验；
- 外部输入不能只依赖 TypeScript 类型。

验收：为 Agent 任务状态机设计完整类型，并用运行时 Schema 校验外部输入。

## 4. 浏览器与 Web 平台（P0，目标 L2）

- URL 到页面显示；
- DNS、TCP/TLS、HTTP；
- HTML/CSS 解析、渲染树、布局、绘制和合成；
- 重排、重绘、合成层和主线程长任务；
- 浏览器缓存、Cookie、Storage；
- 同源策略、CORS、XSS、CSRF；
- Core Web Vitals 和基础性能分析；
- DevTools Network、Performance、Memory 和 Source Map。

Web 能力：

- Web Worker、Service Worker；
- SSE、Fetch Stream、WebSocket；
- 文件上传、下载和大文件处理；
- AbortController；
- IntersectionObserver、ResizeObserver。

验收：分析一次首屏慢、交互卡顿或请求失败，给出测量、定位和优化顺序。

## 5. React / Next.js 与 Vue（P0/P1）

### React / Next.js（P0，目标 L3）

- 函数组件、Hooks、闭包与依赖；
- 状态更新、批处理和渲染触发；
- 组件边界、受控与非受控；
- Context 与外部 Store；
- Server/Client Component；
- SSR、SSG、ISR 和 CSR；
- 数据获取、缓存、错误边界和 Suspense；
- 服务端与客户端安全边界。

### Vue（P0，目标 L2～L3）

考虑美团实际技术栈，Vue 不再仅作为 P1：

- 响应式和依赖追踪；
- `ref`、`reactive`、`computed`、`watch`；
- 生命周期和组件通信；
- 路由与状态管理；
- Vue 与 React 更新模型差异；
- 实习项目中的真实链路和取舍。

不同时深挖两套完整源码。根据目标岗位和实习经历调整叙事重点。

## 6. Node.js 与 BFF 基础（P1，目标 L1～L2）

- Node 事件循环与浏览器差异；
- CommonJS、ESM；
- Buffer、Stream；
- 服务端环境变量和密钥；
- API Route、Server Action、BFF 的边界；
- 进程、错误、日志和优雅退出；
- Node 不等于完整后端可靠性方案。

验收：解释一次前端请求如何经过 BFF 到达数据源，以及服务端和客户端安全边界。

## 7. 工程化、测试与质量（P0，目标 L2～L3）

- Vite / Webpack 的入口、依赖图、转换、打包和分包；
- ESM、CommonJS、Tree Shaking；
- 包管理、锁文件和依赖冲突；
- ESLint、格式化和提交检查；
- 单元、组件、端到端测试边界；
- 错误监控、Source Map 和前端日志；
- CI/CD 和多环境配置。

验收：为一个前端切片补单测、关键端到端路径和构建检查。

## 8. 性能与安全（P0，目标 L2）

性能：

- 加载、渲染、网络和运行时性能分开分析；
- 图片、字体和资源策略；
- 分包、懒加载和预加载；
- 长列表与虚拟化；
- 避免无效渲染和主线程长任务；
- 指标必须说明测量工具、环境和基准。

安全：

- XSS、CSRF、CORS 的区别；
- Token、Cookie 和前端存储风险；
- 富文本和模型输出安全渲染；
- 敏感配置不得进入客户端；
- 服务端保存密钥不等于从根本上防止 XSS。

## 9. AI 原生交互（P0，目标 L3）

- Token 流式输出和增量渲染；
- 消息与任务状态机；
- 长任务进度、刷新和断线恢复；
- 取消、重试和人工接管；
- Tool Calling 的确认和权限提示；
- 引用、来源和执行轨迹；
- 乐观更新与服务端真实状态；
- 对话、任务和工作区产品模型；
- 模型输出不可信和安全展示。

独立产物：一个包含输入、运行状态、引用、Tool Trace、失败与重试的 Agent UI 纵向切片。

## 10. 每周维护要求

前端时间不得长期低于 10%。每周至少完成：

- 一次 JS/TS 独立手写；
- 一次组件、状态机或异步 Bug 分析；
- 一次前端项目追问或 3 分钟口述；
- 每两周一次性能或安全排查练习。

## 11. 投递前验收

- 不看资料解释事件循环、浏览器渲染和常见安全问题；
- 能写常见 JS 高频函数和 TypeScript 状态类型；
- 能独立完成一个组件或 Agent UI 切片；
- 能深入解释 React/Next.js 或 Vue 项目的数据流；
- 能使用 DevTools 定位请求、性能或内存问题；
- 能从性能、可靠性、安全和用户体验复盘方案。
