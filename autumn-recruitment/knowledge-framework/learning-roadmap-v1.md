# 阶段1：算法与独立编码

## 目标

从：

> 依赖原题解记忆

提升到：

> 根据题目性质生成算法方案。

## 顺序

### P0

- 哈希表；
- 双指针；
- 滑动窗口；
- 栈与队列；
- 链表；
- 二分查找；
- DFS/BFS；
- 回溯；
- 堆；
- 基础动态规划。

## 验收

随机隐藏专题后：

- 5 分钟判断算法方向；
- 能描述状态或不变量；
- 20～30 分钟独立实现简单/中等题。

## 不追求

- 困难动态规划；
- 复杂图论；
- 刷题数量。

# 阶段3：AI Agent 工程能力

## 目标

从“会调用模型”提升到“理解 Agent 系统”。

## P0

### LLM 基础

- Token；
- Context Window；
- Message Role；
- Structured Output；
- 延迟与成本。

### Agent Runtime

手写：

```text
User Input
→ Context Builder
→ LLM
→ Tool Decision
→ Tool Execution
→ Result Feedback
→ Continue / Finish
```

理解：

- 状态；
- 最大循环次数；
- 错误恢复；
- 权限控制；
- Trace。

### RAG

- 文档解析；
- Chunk；
- Embedding；
- Vector Search；
- Rerank；
- Citation；
- Evaluation。

### MCP

理解：

- 为什么需要标准化工具协议；
- Client / Server 模型；
- Tool 与 Resource 区别；
- 适用边界。

## P1

- LangGraph；
- Agent Workflow；
- Memory；
- 多 Agent。

## 验收

完成一个生产化最小 Agent：

- 前端交互；
- 后端服务；
- 工具调用；
- RAG；
- 状态保存；
- Trace；
- 基础评测。

# 阶段4：项目与面试

## 项目目标

一个项目覆盖三个岗位。

架构：

```text
Vue/React
    |
Backend API
    |
Agent Runtime
    |
Tools / RAG / Database
```

## 面试准备

每个项目准备：

1. 背景和目标；
2. 系统设计；
3. 核心技术难点；
4. 方案取舍；
5. 异常情况；
6. 性能和优化；
7. 如果重新设计会怎么改。
