# 算法训练体系 v3

## 1. 当前基线

历史上完成过约 200 道题，但已经停练约两个月。本轮不把历史题量视为当前掌握证据，统一按“需要重新讲解和验证”处理。

当前风险是：

- Python 容器、模板、边界和调试手感下降；
- 可能记得题目或术语，但无法重新定义状态和不变量；
- 直接做中等题无标签测试会把“遗忘”和“从未理解”混在一起；
- 过早进入混合模拟容易只得到挫败，不能形成可操作错因；
- AI 直接给完整题解会再次制造“看懂了”的错觉。

因此训练顺序从“旧题诊断”改为“从具体例子重建”。

## 2. 训练目标

从：

> 我以前做过这道题，似乎记得写法

转变为：

> 我能从暴力方案出发，解释重复计算，定义状态和不变量，用 Python 独立实现、测试并在间隔后复现。

## 3. 两阶段训练策略

### 阶段 A：重新学习

适用：前两周和所有新主题。

```text
预测暴力
→ 手算具体样例
→ 观察重复信息
→ 定义容器/指针/状态
→ 引导实现
→ 边界与复杂度
→ 自己复述
```

默认 `/tutor` A1，连续卡住后最多 A2。AI 一次只问一个问题，不先倾倒完整解释。

### 阶段 B：独立与混合

只有同一模式至少完成一个锚点题和一个引导题后，才进入：

```text
10 分钟 A0 独立尝试
→ 必要时升级 A1
→ 完整实现
→ D+7 无辅助复现
→ 隐藏标签进入混合题池
```

第一次正式 60～90 分钟混合模拟，必须等至少 12 道核心题通过 D+7。

## 4. 单题闭环

```text
题目 ID：
题目信号：
具体输入手算：
暴力方案：
暴力重复计算了什么：
候选优化：
核心状态/容器：
核心不变量：
正确性依据：
复杂度：
边界用例：
AI 援助等级：
最终错因：
D+1 / D+3 / D+7：
```

锚点题允许知道专题，但必须先预测暴力。独立题和 D+7 复测隐藏专题和原笔记标题。

## 5. 提示等级

1. A1：只问问题；
2. A2：指出关键性质、反例或算法类别；
3. A3：给状态定义、步骤或伪代码框架；
4. A4：给完整解释或代码。

使用 A3/A4 完成的题只能进入 `LEARNING`，不能计为独立实现。必须在后续无辅助重写。

## 6. 错因标签

每次只选一个主要错因：

- `PYTHON_RUSTY`：容器、语法、模板或调试手感不足；
- `KNOWLEDGE_MISSING`：不知道这个模式解决什么问题；
- `PATTERN_UNKNOWN`：看不出题目性质与候选模式；
- `RETRIEVAL_FAILED`：学过但无法调用；
- `STATE_UNCLEAR`：方向正确但状态或不变量不清；
- `IMPLEMENTATION_FAILED`：思路正确但代码失败；
- `BOUNDARY_FAILED`：循环、下标、空输入或终止条件失败；
- `COMPLEXITY_FAILED`：方案无法满足数据规模；
- `SOLUTION_MEMORY`：依赖记忆中的原题解片段；
- `IO_OR_DEBUG_FAILED`：ACM 输入输出或调试失败。

前两周优先修复 `PYTHON_RUSTY`、`KNOWLEDGE_MISSING`、`STATE_UNCLEAR`，不急于追求识别率。

## 7. 五周训练结构

### Week 0：Python 与最小闭环

- 两数之和；
- set 去重；
- 字符计数；
- 双指针回文；
- 二分查找；
- 有效括号。

目标：恢复容器、循环、测试、复杂度和最小状态解释。

### Week 1：局部模式

- 哈希；
- 双指针；
- 滑动窗口；
- 栈与单调栈。

目标：每类至少一个状态轨迹和一个完整实现。

### Week 2：链表与二分

目标：指针重连、虚拟头节点、快慢指针和区间不变量。

### Week 3：树、图、回溯与堆

目标：画搜索空间、定义递归函数语义和访问状态。

### Week 4：基础 DP、贪心、区间与第一次正式模拟

目标：状态、转移、初值、遍历顺序，以及对已学内容的混合迁移。

## 8. 复测

```text
D+1：不看资料复述问题、暴力、状态和不变量
D+3：写核心循环、递归语义或状态转移
D+7：从空文件完整实现并自测
D+14：隐藏专题混入同阶段题池
```

- 锚点题讲解后也必须复测；
- D+7 失败则回到引导学习，不通过背答案补救；
- 连续两次无关键提示完成后才降低频率。

## 9. 每周最低产出

在工作日碎片时间下，不硬追求原先的高题量：

| --- | ---: | ---: | ---: | ---: |
| Week 0 | 4～6 | 2～3 | 0 | 0 |
| Week 1 | 4～6 | 3～4 | 2～3 | 30～45 分钟小测 |

- 至少 12～18 道核心题通过 D+7；
- 能口述暴力到优化、状态、不变量和复杂度；
- 第一次混合模拟能够识别真实淘汰风险。

## 11. AI 使用边界

人必须完成：

- 首次暴力方案；
- 具体样例手算；
- 核心状态和不变量的首次表达；
- 关键代码、测试和复测；
- 最终用自己的话解释。

AI 可以：

- 苏格拉底式追问；
- 分级提示；
- 生成反例和边界；
- 审查复杂度和代码；
- 在用户连续卡住后讲解；
- 维护题单、记录和复测。

AI 生成的完整答案不能计入掌握度。

## 12. Python 定位

Python 是算法和现场通用编码主语言。恢复顺序：

1. `list`、`dict`、`set`、字符串和循环；
2. 排序、自定义 `key`、`deque`；
3. `bisect`、`heapq`；
4. 链表、树、图结构；
5. 递归、回溯和 DP；
6. ACM 输入输出和手动调试。

TypeScript 与 Java 不用于日常刷题主线，但后续保留岗位专项手写。
