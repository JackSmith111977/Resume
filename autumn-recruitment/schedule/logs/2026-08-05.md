### P0-01 两数之和

状态：INVALID_RETEST / REVIEW  
结果：未通过有效 D+1 复测。

用户独立提交：

```python
nums = list(map(int, input().split()))
target = int(input())

mem = dict()

for i, x in enumerate(nums):
    if target - x not in mem:
        mem[x] = i
    else:
        print(mem[target - x], i)
        break
```

独立部分：

- 核心哈希循环正确；
- 能得出时间 O(n)、空间 O(n)；
