# 每日记录目录

## 命名

```text
YYYY-MM-DD.md
```

同一天多个任务写入同一文件，按任务 ID 分节，不为每个小任务创建独立文件。

## 创建方式

1. 复制 [`../daily-log-template.md`](../daily-log-template.md)；
2. 填入当天容量、到期复测和主任务；
3. 先完成 Human First，再记录 AI 协作；
4. 写入可见产物、验收和下一步；
5. 同步更新 [`../progress-ledger.md`](../progress-ledger.md)。

## AI 规则

AI 可以创建和压缩记录，但不得：

- 替用户填写未发生的独立思考；
- 把 AI 生成内容写成用户已掌握；
- 删除失败、卡点和待核验内容；
- 未经证据升级任务或能力状态。

记录重点是证据和下一步，不是完整聊天转录。
