## 2. 已教学内容

### 客户端与服务端

- 客户端是主动请求能力的程序；
- 服务端是等待并处理请求、提供能力的程序；
- 服务端程序不等于承载它的服务器机器；
- 一台机器可以运行多个服务端进程，同一服务也可以启动多个实例。

### 请求与响应

```text
请求：客户端表达“想做什么”，并携带必要数据
响应：服务端表达“处理结果是什么”，包括成功、失败或返回数据
```

浏览器与后端通常处于不同进程，甚至不同机器。浏览器不能直接调用后端进程里的普通函数或修改其变量，而是发送请求；后端负责身份、权限、参数和状态校验，再决定是否修改自己的状态。

### 通信边界纠正

进程之间并非只能通过 Web 请求通信：同机进程还可使用管道、共享内存等 IPC；浏览器与远程后端通常通过网络请求和响应通信。本节只建立 Web 抽象模型。

### 结果未知与 requestId

```text
客户端发送创建请求
→ 服务端创建成功
→ 响应在返回途中丢失
→ 客户端只知道“没有收到结果”
```

未收到响应不能证明服务端没有执行。同一次逻辑操作的重试沿用同一个 `requestId`；新的逻辑操作生成新的 `requestId`。内容哈希不能单独区分“重试”和“用户主动提交两次相同内容”。
