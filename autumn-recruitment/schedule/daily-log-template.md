## 6. 验收

### 通用四门

- [ ] Explain：不看资料讲清楚
- [ ] Predict：预测新输入、异常或边界
- [ ] Modify：改变一个条件仍能处理
- [ ] Test：有测试、反例、演示或模拟证据

### 由具体到抽象

- [ ] 能描述一个具体样例的完整状态变化
- [ ] 能解释关键机制或不变量
- [ ] 能说明至少一个失败模式
- [ ] 能与一个相邻概念或方案比较
- [ ] 能迁移到一个新场景或面试问题

### AI 代码追加

- [ ] 审查完整 Diff
- [ ] 能解释关键数据流和分支
- [ ] 能修改一个小需求
- [ ] 能判断至少一个失败测试
- [ ] 没有擅自扩大范围

### 简历追加

- [ ] 事实由本人确认
- [ ] 团队成果和个人贡献分离
- [ ] 指标有来源或已删除
- [ ] 技术结论准确
- [ ] 能回答对抗性追问
