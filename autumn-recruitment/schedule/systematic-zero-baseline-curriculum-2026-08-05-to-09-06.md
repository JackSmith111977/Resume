# 2026-08-05 ～ 2026-09-06 系统性零基线课程主线

> 目标岗位：AI Agent 应用开发 / AI 应用全栈优先，全栈其次，前端 / AI 前端作为稳定方向。  
> 教学基线：全部核心知识按首次系统学习处理；已有经验只用于加速验收，不用于跳过课程。  
> 执行规则：本文件负责“学什么和先后顺序”；原日历负责日期、求职、项目与复盘任务。发生冲突时，未完成前置课程的产出型任务必须降级为课后练习。

## 1. 总体能力地图

```text
编程与计算机最小模型
        ↓
Web 请求与数据流
        ├─ 前端：浏览器、JS/TS、框架、状态、性能与安全
        ├─ 后端：API、Spring、数据库、事务、异步与可靠性
        └─ Agent：模型调用、Tool、Loop、RAG、Trace 与 Eval
                         ↓
                  全栈 Agent MVP
                         ↓
                  简历、项目深挖和面试
```

算法是独立并行主线，继续使用 Python 零基线路线；它与本课程共享状态、不变量、复杂度、测试和无辅助复现方法。

## 2. 课程模块与严格依赖

### A. 计算机与编程基础

#### `FND-01` 程序是如何运行的

- 程序、代码、数据、内存、文件；
- 进程和线程的最小区别；
- 输入、处理、输出、错误和状态；
- 客户端与服务端为什么是两个程序。

通过证据：能用自己的话描述“点击按钮后，至少有哪些程序参与”。

#### `FND-02` 函数、模块、接口和状态

- 函数为什么存在；
- 参数、返回值、副作用；
- 模块与依赖；
- 接口是约定，不等于具体实现；
- 状态为何需要显式记录。

通过证据：能区分输入、状态、输出和副作用。

#### `FND-03` 调试、测试、Git 与命令行

- 报错、日志、断点和最小复现；
- 单元测试和集成测试；
- 工作区、暂存区、提交、分支和 worktree；
- 进程退出码、环境变量和配置文件。

通过证据：能从一个失败现象提出可验证的定位步骤。

### B. Web 与计算机基础

#### `WEB-01` 一个请求的完整世界

```text
用户操作
→ 浏览器前端
→ HTTP 请求
→ 后端 API
→ 业务逻辑
→ 数据库或外部服务
→ HTTP 响应
→ 前端更新页面
```

先建立角色和数据流，不先讲协议细节。

#### `NET-01` DNS、TCP、TLS、HTTP

- 域名如何找到服务器；
- TCP 解决什么；
- TLS 为什么需要；
- HTTP 请求与响应由什么组成；
- 超时、断开和重试分别意味着什么。

#### `OS-01` 进程、线程、线程池、阻塞与异步

- 为什么一个请求不能无限占用线程；
- 队列和 Worker；
- 并发不等于并行；
- 异步只改变等待方式，不自动保证可靠。

#### `DB-01` 数据库最小模型

- 表、行、列、主键；
- SQL 增删改查；
- 索引为什么能加速；
- 事务为什么存在；
- 并发修改会出现什么问题。

#### `OBS-01` 日志、指标与 Trace

- 日志记录离散事件；
- 指标观察总体趋势；
- Trace 串联一次请求或任务的跨组件路径；
- 请求 ID、任务 ID 和 Trace ID 的区别。

### C. 前端主线

#### `FE-01` 浏览器、HTML、CSS 与 DOM

- 页面由什么组成；
- DOM 是什么；
- 布局、绘制和用户事件；
- 前端为什么需要管理状态。

#### `FE-02` JavaScript 执行模型

- 调用栈、任务队列、事件循环；
- Promise、async/await；
- 并发请求、取消与错误传播；
- 闭包和作用域的实际用途。

#### `FE-03` TypeScript 与运行时边界

- 静态类型解决什么；
- 类型不会自动校验线上数据；
- 泛型、联合类型、类型收窄；
- API 数据的运行时校验。

#### `FE-04` Vue / React 的组件与状态流

- 组件为什么存在；
- Props、事件、局部状态和全局状态；
- 更新、渲染和副作用；
- 服务端状态与页面状态的区别。

#### `FE-05` 工程质量

- 构建、模块、测试；
- 性能测量；
- XSS、CSRF、CORS；
- 错误边界、加载态、空态和失败恢复。

#### `FE-06` AI 原生交互

- 流式输出；
- 长任务与刷新恢复；
- Tool 确认；
- Citation 和 Trace 展示；
- 用户取消与部分结果。

### D. 后端与全栈主线

#### `BE-01` API 与分层

- Controller、Service、Repository；
- DTO、领域对象和数据库实体；
- 参数校验、错误码、认证和权限；
- 一次请求的调用链。

#### `BE-02` Java 与 Spring Boot 最小机制

- 对象、接口、异常；
- Bean 与依赖注入；
- Spring MVC；
- AOP 和事务代理的直觉模型。

#### `BE-03` 数据、事务和并发更新

- 事务边界；
- 隔离与 MVCC 的问题背景；
- 唯一约束、乐观锁和条件更新；
- 缓存的用途和一致性风险。

#### `BE-04` 异步任务与状态机

```text
接收请求
→ 创建任务
→ 派发
→ Worker 执行
→ 更新进度或结果
→ 客户端查询或订阅
```

- 任务状态；
- 队列和线程池；
- 轮询、SSE、WebSocket；
- 任务取消和超时。

#### `BE-05` 可靠性

- 幂等；
- 重试和副作用；
- 重复消费；
- 创建成功但派发失败；
- Worker 成功但状态更新失败；
- 补偿、Outbox 和人工恢复的适用问题。

### E. AI Agent 主线

#### `AG-01` 大模型调用的最小模型

- 消息、System/User/Assistant；
- Token、上下文窗口、延迟和费用；
- 流式与非流式；
- 模型是生成器，不是直接执行程序。

#### `AG-02` Structured Output

- 为什么自然语言输出难以被程序稳定消费；
- Schema、解析和校验；
- 格式错误与重试；
- 静态类型和运行时数据的边界。

#### `AG-03` Tool Calling

```text
程序提供工具描述
→ 模型表达调用意图和参数
→ 宿主程序校验并执行
→ 工具结果返回模型
```

- 模型不直接拥有真实权限；
- 只读与有副作用工具；
- 参数校验、超时和权限。

#### `AG-04` Agent Loop 与状态

- 观察、决策、行动、结果；
- 继续、结束、等待工具、等待用户；
- 最大轮数；
- 状态持久化和恢复；
- 普通模型调用与 Agent 的边界。

#### `AG-05` Workflow 与 Agent

- 确定流程和动态决策；
- 何时不应该使用 Agent；
- 可预测性、成本和可测试性的取舍。

#### `AG-06` RAG 与真实 Citation

```text
文档解析
→ 切分
→ 建索引
→ 查询与召回
→ 放入上下文
→ 生成答案
→ 映射真实引用
```

- RAG 解决知识访问，不自动等于记忆；
- 召回错误、回答错误和引用错误是不同问题。

#### `AG-07` Context 与 Memory

- 当前上下文；
- 会话状态；
- 短期与长期 Memory；
- 存什么、何时读、何时忘；
- 隐私和过期信息。

#### `AG-08` Trace 与 Evaluation

- Trace 记录一次任务如何发生；
- Evaluation 判断结果是否达到标准；
- Demo 能跑不代表稳定；
- 固定测试集、任务成功率、工具选择、引用正确性、延迟和成本。

#### `AG-09` MCP

- 客户端、服务器、工具与资源；
- 它解决连接和能力暴露标准化；
- MCP 与 Tool Calling 的层次区别；
- 在单 Agent Tool 闭环完成前不做复杂部署。

#### `AG-10` 安全、权限、成本与恢复

- Prompt Injection；
- 最小权限和人工确认；
- 超时、重试、预算和最大循环；
- 部分成功和失败恢复。

### F. 项目、简历与面试


## 5. 第一节课

### `CURR-FND-01` 程序与 Web 系统的最小心智模型

本节依赖：无。

本节目标：用户能够区分并连接以下对象：

```text
代码
程序
进程
线程
浏览器前端
后端服务
数据库
请求
响应
状态
```

教学顺序：

1. 程序与正在运行的进程；
2. 输入、状态、处理和输出；
3. 浏览器与后端为什么是两个程序；
4. HTTP 请求只是两个程序通信的一种消息；
5. 数据库为何独立保存长期状态；
6. 用“提交文件并查看解析结果”串成第一条主链路。

课后练习：在提供组件卡片后，由用户重新排列主链路，而不是要求其凭空画完整系统。

明确不做：TCP/TLS 细节、Spring 内部机制、线程池参数、事务、MQ、幂等、Agent 状态图。
