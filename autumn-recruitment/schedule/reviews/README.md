# 周复盘目录

## 命名

```text
YYYY-Www.md
```

示例：`2026-W32.md`。

## 创建方式

1. 复制 [`../weekly-review-template.md`](../weekly-review-template.md)；
2. 汇总本周每日记录和 [`../progress-ledger.md`](../progress-ledger.md)；
3. 只依据代码、图、测试、口述、投递和面试反馈更新状态；
4. 删除、降级或拆分未完成任务；
5. 生成下周最多五个 P0 和具体日期。

## 必须输出

- 本周真正新增的独立能力；
- 本周新增的求职证据；
- 重复失败和主要错因；
- 项目是否仍在 MVP 护栏内；
- 删除或停止了什么；
- 下周最多五个 P0；
- 每个 P0 的最小任务和验收证据。

AI 可以聚合和提出候选调整，但 P0 升级、能力升级和范围变化由用户最终确认。
